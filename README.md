# nfx::silicon

A lightweight, zero-dependency C++20 hardware emulation library.

## Requirements

- C++20 compiler
- CMake 3.25+

## Build

### CMake options

| Option                    | Default | Description      |
| ------------------------- | ------- | ---------------- |
| `NFX_SILICON_BUILD_TESTS` | `OFF`   | Build unit tests |
